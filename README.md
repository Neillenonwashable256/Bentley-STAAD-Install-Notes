## ⚠️ Troubleshooting Common Errors

If you see errors, try these fixes in order.

### Error: Setup Failed
This often happens if you have an older version of the Bentley Connection Client. 
*   Uninstall the existing Connection Client via the Windows Settings app.
*   Download the latest version from the Bentley support website.
*   Install the client again, then attempt the STAAD.Pro installation.

### Error: Missing Prerequisites
The installer may ask for Microsoft .NET Framework or Visual C++ Redistributable packages. 
*   Visit the official Microsoft website.
*   Search for "latest supported Visual C++ redistributable".
*   Download and install the x64 version.
*   Restart your computer and run the STAAD.Pro installer again.

### Error: Access Denied
Windows 11 may block the installer for security reasons.
*   Temporarily disable your antivirus software.
*   Right-click the setup file.
*   Choose "Properties".
*   Check the "Unblock" box at the bottom and click "Apply".

## 🛡️ License Activation

After installation, you must activate your license.
1.  Open the "Bentley License Tool" from your Start menu.
2.  Select "License Checkout" or "Activation".
3.  Enter your organization’s server name and activation key.
4.  Click "Test Server Connection" to verify your credentials.
5.  If successful, the software will launch.

## 📈 Performance Tips for Windows 11

Windows 11 includes features that may interfere with heavy engineering software. 

*   **Virtualization Settings:** Disable "Memory Integrity" in Windows Security if the program crashes on startup.
*   **Graphics Drivers:** Always keep your GPU drivers updated. Use the manufacturer website (Nvidia or AMD) rather than the basic Windows Update driver.
*   **Updates:** Ensure Windows is current. Sometimes a pending Windows Update causes conflicts with software registration.
